Topology symbols

Site stack: Site ID Surge → Site ID → RAN → site readiness → CSG router → Seq. CSG “NY” is displayed as CSG NY Installed (not yet installed). NY RFI means not yet ready for installation; RFI means ready for installation. CSG: Cell Site Gateway. FO: Fiber Optic. ACC: Access Router, per your reference. Router color shows installation/integration progress, not live health.

Reading this topology

Rings are arranged by sequence. Connections follow the Excel Segment field, with each ring in its own lane. Links to other rings end at a labeled CSG reference showing the destination site and ring; repeated CSG symbols represent the same site, not additional sites. Station endpoints represent ACC / Access Routers.

How candidates are identified

Network-ready candidate: a continuous path to a Station / ACC using only “6. Pulling done” links, with every intermediate site already Integrated or On-Air. The candidate itself must not be integrated or on Freeze. An unfinished upstream site blocks the path even when its FO is Pulling done; an eligible alternate path can still qualify the site.

Ready to schedule: a network-ready candidate whose site is Installed and whose CSG is Installed or Integrated. Other network-ready candidates show the equipment work still needed. This snapshot does not confirm optical tests or commissioning.
